# Dashboard

A modern Next.js + React dashboard with **authentication**, **role-based access control**, and powerful **data management & visualization** features.

## ✨ Features
- 🔒 **Protected & Public Routes** — Secure pages with authentication
- 👥 **Role-Based Access** — Manage permissions for editing and viewing data
- 📊 **Dynamic Tables & Charts** — Real-time data analysis & visualization
- 🎨 **Dark & Light Mode** — User-friendly theme switching
- 📱 **Responsive Design** — Works across desktop, tablet, and mobile

## 🛠 Tech Stack
- Next.js 15
- React Hook Form + Zod
- Tailwind CSS + shadcn/ui
- Chart.js / Recharts
- Prisma / Database integration
- JWT Authentication
